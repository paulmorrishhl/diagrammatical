# Release checklist

- [ ] Ruff, full Pytest, package verification, release check and `git diff --check` pass.
- [ ] Every example and calibration self-check passes.
- [ ] Mermaid adversarial fixtures and all SVG/PNG export tests pass.
- [ ] Visual baselines are explicitly reviewed; CI does not update them.
- [ ] Local marketplace install discovers all seven commands and representative workflows pass.
- [ ] Versions match and package contains no secrets, local paths, caches or temporary files.
- [ ] Dependency licences, attribution, security and contribution guidance are reviewed.
- [ ] Every SPEC section 27 item has direct evidence and no required item is partial.
- [ ] Maintainer separately authorises any push, tag, publication or GitHub release.
