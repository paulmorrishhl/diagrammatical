# Changelog

## 0.1.0 — intended initial release

- Five semantic diagram types with reviewed examples and shared creation/revision workflow.
- Project-owned brand onboarding, calibration, semantic precedence and contrast validation.
- Bounded Mermaid editorial import for flowchart/graph, sequenceDiagram and Gantt.
- Deterministic standalone SVG extraction and explicit optional Playwright PNG export.
- Canonical mechanical self-check, package checks and visual-regression workflow.
